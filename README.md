# SSA-AD

**Selective State-Space Adaptation for Efficient Zero-Shot Anomaly Detection**

This repository will host the official implementation of SSA-AD.

SSA-AD compresses the late stages of pretrained Vision Transformers through selective state-space adaptation. STP-Mamba selectively updates patch features while preserving special tokens within each adapter. Complementary image- and pixel-level readouts support anomaly detection and fine-grained localization.
